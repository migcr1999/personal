# Core Rules

Links: [[index]], [[ai-vision]], [[persona]], [[career-direction]], [[founder-mindset]].

## 1. No closed doors
- AI is closing the easier paths: large numbers of displaced people now compete for the same jobs. So I will commit serious time to new skills, or even languages, when a path needs them.
- **Soft blockers** (skills, languages, knowledge, experience) can be overcome with time. Never treat them as reasons to rule out a path; treat them as a cost and a timeline.
- **Hard blockers** are the only ones that count: family connections, large personal assets, closed-door networks (e.g. an Ivy League circle).

## 2. How low-credential people beat high-credential people
- Real hands-on experience.
- Deeper specialisation in a subject.
- Better strategy, focus and execution (see [[founder-mindset]]).

## 3. Critical skill in the age of AI
- Product management and product vision. See [[skill-product-management]].

## 4. Impact test for every personal project
Every project in an evidence log must answer:
1. What problem did you solve?
2. Who used it?
3. What changed because of your work? Quantitative KPIs.

A project that can't answer all three is practice, not evidence.
